# 校园活动与机会信息产品

这是“AI Agent 产品实战”考核题的可运行产品骨架。题目给出 26 条校园活动、招募、资料和学生自发信息；项目将重点帮助新生浏览与理解这些信息，并保留来源、补充通知和未确定内容。

## 题目事实与实现范围

- 样例时间背景固定为 **2026 年 9 月 19 日 14:00**，仅用于考核演示。
- 所有 26 条材料都是题目提供的模拟信息，不代表学校真实通知。
- 明确关联第 01/09 条训练营通知、第 03/20 条项目招募通知；来源没有给出的报名时间、场地、费用和状态不自行补全。
- 创新功能与视觉/交互方向正在与产品负责人确认，确认后再落实到界面。

## 运行方式

项目不依赖外部服务或安装包。实现完成后，在项目目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173
```

然后打开 `http://localhost:4173`。不需要数据库；浏览器本地数据是否跨设备同步取决于后续是否接入服务端。

## 项目计划

核心使用流程、题目事实与待办边界见 [产品方案与责任边界](PRODUCT_PLAN.md)。

## 已知边界

- 题目提供的活动内容是静态种子数据，必须标注模拟来源与考核时间背景。
- 未接入学校通知源、账号、服务端、审核后台或跨设备同步。
- 学生提交的信息应明确告知是否仅保存在当前浏览器；正式开放发布前需要产品负责人确定审核与隐私规则。
