# 校园活动与机会信息产品

这是“AI Agent 产品实战”考核题的可运行产品原型。题目给出 26 条校园活动、招募、资料和学生自发信息；项目帮助新生浏览与理解信息、跟进通知变化，并标出缺失和需要核对的内容。学生发布会存入服务端待审核，只有通过审核后才会进入公开列表。

## 考官预览

可直接打开 [在线功能预览](https://kenyu777.github.io/0/)。预览站使用模拟数据展示主要页面和交互；发布、反馈、收藏及屏蔽操作仅用于演示，不连接本机发布审核服务。考核提交请使用本仓库链接：<https://github.com/kenyu777/0>。

## 题目事实与实现范围

- 样例时间背景固定为 **2026 年 9 月 19 日 14:00**，仅用于考核演示。
- 所有 26 条材料都是题目提供的模拟信息，不代表学校真实通知。
- 明确关联第 01/09 条训练营通知、第 03/20 条项目招募通知；来源没有给出的报名时间、场地、费用和状态不自行补全。
- 视觉采用用户指定的 iPhone 式简洁、圆润、易触达方向，移动端使用底部标签导航和底部抽屉。
- 题目数据标注补充通知、变更、缺失、待核实等线索。材料中没有无法调和的直接冲突；发生明确更新时保留原文并链接到补充通知。
- 收藏和屏蔽记录保存在当前浏览器；学生发布保存到服务端，审核通过后对所有访问者公开。反馈入口使用占位邮箱 `xxx@xxx.com`，会打开预填邮件草稿，由用户确认发送。

## 核心功能

- 按关键词、类别、来源和信息线索筛选，查看活动详情与原始题目摘要。
- 跟踪第 01/09 条和第 03/20 条补充关系；单独分类缺失信息、待核实和风险线索。题目中没有无法调和的权威冲突，因此冲突筛选计数为 0。
- 收藏活动并提交学生信息审核；可以通过邮件举报题目信息、屏蔽/恢复单条学生发布，并查看屏蔽历史。
- 适配移动端的底部标签栏、触控按钮与圆角详情面板。

## 本机与局域网演示

项目使用 Node.js 内置模块，无第三方依赖。首次运行前设置审核口令：

```powershell
Copy-Item .env.example .env
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

将生成的随机值填入 `.env` 的 `ADMIN_TOKEN`，再启动服务：

```powershell
npm start
```

打开 `http://localhost:4173`。用户发布不需要注册账号；随机发布凭据只保存在提交者当前浏览器，用于查看“我的发布”状态。管理员审核入口为 `http://localhost:4173/admin.html`。审核口令不保存在浏览器；关闭或刷新审核页后需要重新输入。

局域网演示配置、数据目录、图片限制和考官访问步骤见 [局域网演示指南](LAN_DEMO.md)。审核通过的发布和图片分别保存在 `data/posts.json`、`data/uploads/`，重启服务后仍保留。备份整个 `data/` 目录；不要把 `.env` 或 `data/` 提交到代码仓库。Node 发布审核服务仅在本机运行；公网地址只提供静态模拟预览，不处理真实发布或审核。

## 已知边界

- 题目提供的活动内容是静态种子数据，必须标注模拟来源与考核时间背景。
- 未接入学校通知源、学生账号、审核日志、自动内容识别、通知邮件或申诉流程。
- 学生发布信息服务端待审，审核通过后才会公开；发布凭据保存在提交者当前浏览器，清除浏览器站点数据后将无法查看自己的发布状态。
- 审核后台使用单一共享管理员口令。公网部署时必须使用强随机口令、HTTPS 和持久化磁盘，并制定人工审核规范与数据备份方式。
- “反馈管理”提供占位邮箱和邮件草稿入口；只有用户在邮件客户端确认发送后，开发者才可能收到反馈。原型无法确认送达或同步采纳状态；屏蔽对象是单条信息，不是发布账号。
- 本服务不支持多个 Node 进程共享数据，也不提供用户禁言或封号能力。扩大使用规模前需升级数据库、权限模型、审核记录和内容治理流程。
